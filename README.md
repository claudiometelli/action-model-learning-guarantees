# Action Model Learning with Guarantees

In this work we will present the problem approach, the design, the implementation and evaluation of the [Action Model Learning algorithm (Aineto and Scala 2024)](https://arxiv.org/abs/2404.09631), which aims to create sound and complete PDDL models starting from a set of demonstrations.
The whole report of the work can be found in AML_report.pdf, inside this repository
